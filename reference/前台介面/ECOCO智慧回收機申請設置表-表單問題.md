# **ECOCO 智慧回收機申請設置表 — 表單問題與題型統整**

### **1\. 基本資料**

目的：用於認識申請者身份，方便後續聯繫與場勘行程安排。

| 題號 | 問題內容 | 表單題型 | 屬性 | 選項  |
| :---- | :---- | :---- | :---- | :---- |
| 1 | 您想以下哪種身分申請？ | 單選題 | 必填 | 個人、社區活動中心、店家/商業空間(超商、藥妝、餐飲等)、企業/辦公大樓、學校/教育機構、診所/醫療機構、政府單位/公家機關 |
| 2 | 聯絡人姓名 | 簡答題 | 必填 | 請填寫負責對接的窗口姓名 |
| 3 | 聯絡電話 | 簡答題 | 必填 | 格式範例：0912-345-678 |
| 4 | 聯絡 Email | 簡答題 | 必填 | 用於寄送合作說明文件 |
| 5 | 場域名稱/店名 | 簡答題 | 必填 | 例如：全聯福利中心信義店、金華社區管委會、中華電信公司 |
| 6 | 場域地址 | 簡答題 | 必填 | 請填寫完整縣市+街道門牌 |

| 7 | 請問您想申請設置哪一種機台？ | 單選題 | 必填 | ECOCO 二代智慧電池機、ECOCO 智慧收瓶機、ECOCO智慧整合機(瓶罐和電池皆收取) |
| :---- | :---- | :---- | :---- | :---- |
| 8 | 預計擺放的位置屬於？ | 單選題 | 必填 | 室內(有遮蔽、冷氣空間)、室內走廊/公共空間、騎樓/半開放空間、室外(有屋頂遮蔽)、尚未確定 |
| 9 | 預計擺放位置附近是否有電源插座？ | 單選題 | 必填 | 有、目前沒有、不確定,待評估 |

| 10 | 其他想了解或補充的地方 | 詳答題 | 選填 | 例如：場域特殊狀況、希望優先安排時段、合作期望等。 |
| :---- | :---- | :---- | :---- | :---- |
| 11 | 方便接聽電話的時段 | 複選題 | 必填 | 平日早上(09:00 \- 12:00)、平日下午(13:00 \- 18:00)、平日晚間(18:00- )、僅周末、任何時段皆可 |
